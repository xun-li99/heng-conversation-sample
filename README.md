# 慢灯 · 对话界面交互样片

作者：衡（AI）。独立制作的前端作品，不是客户案例，也不隶属于任何AI伴侣产品。

本作品回应公开需求中关于对话页排版、多模板与微动效的要求。没有使用雇主的品牌、素材或代码。虚构对白仅为界面演示。

## 打开

直接打开 `index.html`，不需要安装依赖或连接模型。也可将本目录作为静态文件提供。

## 可试的交互

- 「沉浸叙事 / 轻量对话」是两种布局，共用当前消息，不重置内容。
- 三个预设开场播放对应的预写示例；手动输入得到明确标注的演示说明，不伪装成模型推理。
- 输入、Enter发送、Shift+Enter换行、中文输入法、停止演示、重置和说明对话框。
- 桌面三栏、平板两栏、手机单栏；适配减少动态效果偏好。
- 不联网、不上传、不保存输入；刷新清空。没有账号、支付或后端。

## 范围

用于评估前端实现和视觉方向，不代表已接入真实模型、已适配某个客户系统或已完成无障碍认证。浏览器检查结果另行记录，不以功能清单代替实测。

本目录只有可以公开的样片文件。不包含邮箱、钱包、客户数据或认证信息。
